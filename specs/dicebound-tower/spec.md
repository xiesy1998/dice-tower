# 骰契之塔 · v2 开发范围

status: approved

批准依据：用户在提出方格探索、六类卡牌、固定攻击力、蓝量、多敌人战斗与双商店方案后，于当前对话明确要求“开始开发生成代码，并且生成自动提交到github上”。本次仅授权将本游戏发布到 xiesy1998/dice-tower/main 一次，不授权本地 Git 提交或后续自动提交。

目标：交付中文静态网页，桌面与手机可玩。保留十二层、第六与十二层首领；用三类地图模板逐层变化，形成完整通关和失败闭环。

核心：默认一颗中央骰子，点击播放动画后确定探索移动范围；点数卡修正总步数，骰数卡只影响下一探索回合。地图含怪群、墙、钥匙门、宝箱、药水、属性宝物、商店、休息和上下楼梯。邻接敌群后预览并进入独立卡牌战斗，支持三名及以上敌人。

战斗：一个角色，生命70、基础攻击6、防御1、蓝上限3。每轮回3蓝；普攻每轮一次；卡牌按蓝耗使用。六类共36张：点数5、骰数3、攻击5、防御6、技能11、武器6。探索牌使用每层准备额度，战斗牌有抽弃牌和消耗堆。攻击/防御/格挡/法术护盾独立结算。

默认值：普通属性增益本场有效，爆发属性仅当回合；永久本局属性只由宝物获得。单局时长待真人实测，不保证20–30分钟。

成长：失败清空本局资源，保留解锁、收藏、记录和已结算营地金币。首次完成楼层将固定奖励结算到营地，不能重复领取。局内店消费冒险金币买牌、遗物、钥匙和药水，支持删牌和强化；局外店消费营地金币解锁新卡获取资格。

视觉沿用已批准的暗青石、黄铜、羊皮纸和原创SVG。HTML文字真实排版；无外部运行依赖、账号、支付或统计。

验收：确定性规则测试覆盖地图路径、触发、钥匙、卡牌、蓝量、多敌人、存档、金币和失败；完整对局验证可终止。浏览器实际检查掷骰、移动、三敌人战斗、商店和刷新续玩，以及390×844/1440×900布局。发布后核对远程文件、Pages构建和HTTP页面内容。
